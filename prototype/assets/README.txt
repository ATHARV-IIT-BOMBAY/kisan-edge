Drop 4 leaf photos here to replace the emoji placeholders. Use these exact names:

  tomato.jpg    — a tomato leaf with Late Blight (dark blotches)
  cotton.jpg    — a cotton leaf with Bacterial Blight (angular spots)
  healthy.jpg   — a clean, healthy leaf
  blurry.jpg    — a deliberately blurry / bad photo (shows the "retake" path)

Square-ish images look best (they're cropped to fill). ~600x600 is plenty.
If a file is missing, the app just shows the emoji instead — nothing breaks.

Where to get them: see the chat for the Google Images and Kaggle commands.
Best source for a demo = the PlantDoc dataset (real field photos, correct labels).
